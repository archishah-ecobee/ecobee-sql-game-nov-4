CASE FILE #1104
📁 The Case

Last night, the Morgan family's smart home was broken into. Nothing was taken from the outside — no smashed windows, no broken locks. Whoever got in used the house's own Ecobee smart home system against it.

The Morgans have Ecobee sensors on every door, motion detectors in the hallways, cameras watching the yard and kitchen, a smart thermostat, and a keypad that arms and disarms their security system. Every single one of those devices keeps a log.

You're the detective. You don't need to search the house — you need to search the data. Use the SQL console below to query the home's device logs, answer each clue, and figure out who broke in.

One more thing: Ecobee's device logs cover the whole street, not just the Morgans' house. If a suspect claims they were home all night, you can check their own house's sensor logs to see if that's true — just filter by house_address.
